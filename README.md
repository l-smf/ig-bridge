# Instagram Triple Username Checker (Cloud)

## نشر مجاني على Render
1. فك ضغط المشروع.
2. ارفع الملفات إلى مستودع GitHub جديد.
3. افتح https://render.com وسجّل الدخول عبر GitHub.
4. اختر **New + → Blueprint** ثم اختر المستودع الذي يحتوي `render.yaml`.
5. وافق على إنشاء خدمة الويب وانتظر اكتمال النشر.
6. افتح رابط الخدمة الذي يعطيك Render.

## الاستخدام
- اختر عددًا صغيرًا في كل دفعة (حتى 300).
- اختر نوع الأحرف، ويمكن إدخال بادئة اختيارية من حرفين كحد أقصى.
- اضغط ابدأ الفحص. الفحص متتابع مع فاصل زمني افتراضي 8 ثوانٍ.
- صدّر النتائج CSV عند الحاجة.

## حدود مهمة جدًا
- لا توجد واجهة عامة رسمية من Instagram تضمن فحص توفر اسم المستخدم.
- فحص صفحات Instagram العامة مجرد مؤشر: 404 قد يشير إلى عدم وجود صفحة، لكنه **لا يثبت** أن الاسم قابل للتسجيل. و200 قد يكون صفحة تسجيل دخول أو استجابة وسيطة.
- لذلك تظهر الحالات: متاح مبدئيًا، محجوز، غير معروف. لا تعتمد على «متاح مبدئيًا» قبل محاولة التسجيل رسميًا داخل Instagram.
- Instagram قد يقيّد طلبات السيرفر أو يغير طريقة عرض الصفحات. لا توجد وسيلة مضمونة لتجنب الحظر.
- النسخة المجانية من Render قد تدخل في وضع الخمول، وقد تتغير حدودها أو شروطها.
- هذه الأداة لا تستخدم تسجيل دخولك، ولا تدوير IP، ولا تجاوز CAPTCHA أو وسائل الحماية.

## محليًا للتجربة
`pip install -r requirements.txt`
`python app.py`
ثم افتح `http://localhost:5000`.
